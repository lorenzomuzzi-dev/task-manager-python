# Task Manager (Python)

Gestore di attività da terminale scritto in Python. Permette di aggiungere, visualizzare, completare ed eliminare attività, che vengono salvate in un file JSON.

## Funzionalità
- Aggiunta di nuove attività
- Elenco delle attività con stato (completata / da fare)
- Completamento ed eliminazione di un'attività
- Salvataggio automatico su file (`tasks.json`)
- Controllo degli input non validi

## Come avviarlo
Serve Python 3 installato.

```bash
python task_manager.py
```
